### 谁来接一张病床

| 一件具体的事 | 谁和谁有关 | 为什么找他们 |
| --- | --- | --- |
| 搬出第一张病床 | [焦檐祖][118] → 面工汤小芹与接生婆 | 宽床过不去窄桥。檐祖把床和愿意同行的人装进内屋，自己侧身过桥。把母女认作同一户的，是长栈和她们的街坊，不是这项异能。见[第一张床是怎么过去的](世界设定.md#第一张床是怎么过去的)。 |

**还在商量的下一班车。** [织星][016]能将抬架的人系上线，[星墙][007]要让人站在盾后的同一幅星图里；这是[迁居榜](异能榜.md)提出的两项分工，并非她们已在这条桥上共同值过班。[寻宝女王][003]能找变重的沟，[海璃][028]能接活人的气，[梁予渡][108]开门要有已知落脚点；三项本事放在一起，也不能替五更港失踪的船长回答他人在哪里。

### 炉边誓约与断角夜

| 留下的东西 | 牵连的人 | 后来怎样了 |
| --- | --- | --- |
| 半张饼 | [灯里][001] ↔ [剑华][011] ↔ [龙音][004] | 旧纸仓回火，灯里引开食墨蛾，剑华砸炉门，龙音挑住梁。她们在冷灶边把饼分了，约好下一回起火先数齐人。剑华还等着听那本烧掉的游记的结尾。 |
| 一张印胡纸 | [龙音][004] → [星墙][007] | 龙音折角救了降城，养父赫连岫死在坠峡的七百骑里。星墙举盾留在城门，妹妹窦红杏也死在那支队伍中。她拿着妹妹画假胡子用的纸去找龙音，不求偿命，只求对方记住：红杏是自己上马的。 |
| 一面樱木盾 | [星墙][007] → [小椛][008] | 小椛来学护住全队，星墙先教数人头，又问队尾摔了人怎么办。这个惯于打头阵的姑娘终于放下盾，让别人领了一回头。 |
| 一面尚未易手的旗 | [雪翎][027] → [龙音][004] | 雪翎为救城射死了长姐的老隼，换来一堡战旗。现在她向龙音递了决斗书，输的人给赢家擎旗一天。战书已经到了，谁会举旗还没有定。 |

### 雾林的种枝与花房

| 留下的东西 | 牵连的人 | 后来怎样了 |
| --- | --- | --- |
| 最后一荚九节豆 | 茧伯 → [小满][002] → [柚芽][021]、[苏兰][025] | 茧伯当年背小满的外婆逃过洪水，王冠后来却收拢各家的老种。小满在王宴上保住豆荚，没保住四户人的芽。她把新豆分给两个朋友，各自等春雨下种；她没去拿一篮菜向第四家讨原谅。 |
| 一片落果地 | [榛果][022] ↔ [柚芽][021] | 模人声的老兽引榛果回头，伤了她；她查明是伐木先断了它的食，两人才在林里另留一片落果地。此后值夜仍要守门，只是不必靠从早到晚关紧一道门来守林。 |
| 共用过的尺，两柄斧 | 茧伯 → [萧镞枝][079] ↔ [严剪春][077] | 替茧伯守过接穗的斧客，曾陪花匠追三年花期。后来她为八家菜园砍下雷击母树的一枝，八个孩子都看见是谁下的手。断口可以再长，严剪春等的嫁接期却没了，花房从此不再请斧客进门。 |

### 甘檐声的旧船

| 留下的东西 | 牵连的人 | 后来怎样了 |
| --- | --- | --- |
| 头一个月的船钱 | [甘檐声][041] → [班蚀][040] → [廉载山][061] | 甘檐声出钱赎下代人挨痛的班蚀。两年后班蚀坐到了出价人的位置；给她搬过三年护墙的廉载山，知道每面墙后都放着等人挨打的凳。甘檐声没有把班蚀做过苦工的日子从船员簿上划去。 |
| 一盏旧灯，一截船钉 | [灯里][001] → [傅煤心][043] ← [祝野杏][135] | 灯里用学籍名卢灯禾教孩子验炉，把第一盏灯留给他；甘檐声视若家人的祝野杏教他用手摸冷船钉，再捏自己的火。后来傅煤心捉到了藏进旧熔龛的矿主，也烧掉了亡工的名字。他拿破案奖牌去补字，仍有三处空白。 |
| 药箱和驮兽的硬套 | [甘檐声][041] → [苗燧白][052] ↔ [荻望实][140] | 苗燧白是甘檐声的干儿子。到渡栈轮值，他遇上愿跟他比谁先喂病号半碗饭的荻望实。驮兽伤了颈，荻望实搬开栈梁、留下白线，苗燧白照线解套；她没保住药箱，重新开诊却多做了几排兽也够得着的水槽。 |
| 一条原本准备装弹簧的铁腿 | [荻望实][140] ↔ [谭滚银][100] | 旧货匠出钱给被夺走铁腿的孩子配新腿，原想在脚尖装上弹簧让孩子跳得高。兽医请匠人坐到矮柜前看孩子穿鞋，才知道他最想自己够着鞋带。钱花在一节真正能弯的膝上。 |
| 满舱鸡蛋 | [甘檐声][041] → [叶刻湾][142] | 叶刻湾曾拿全伙的船打赌，虽把一舱蛋平安运过礁，仍给罚去跟鸡住十天。后来她自己当了队长，追船时本可撞开对方，却把攒足的力气用来停住自家船，让伙计把已经落到船头下的点灯工拉上来。从此船不是赌本。 |

### 白礁归航的人

| 留下的东西 | 牵连的人 | 后来怎样了 |
| --- | --- | --- |
| 一张问诊长凳 | [圣愈][013] ↔ [寻宝女王][003] | 同船人失控后，有人想预先锁住所有服药者。圣愈把长凳搬出来，要求逐人问诊；服过「水手」魔药的寻宝女王第一个排队。轮到她开口，她没拿王号挡过去，真把自己服药的日子告诉了修女。 |
| 一双红靴 | [寻宝女王][003] → [海璃][028] → [澄汐][017] | 白礁倒潮，海璃一声「分」保住六船，哥哥沉在末船。九年后水里的嗓音像极了他，偏认得她在倒潮后第八年才借的红靴。她没下水追哥哥；如今要和澄汐找的是一张活人的嘴。 |
| 一只画着鱼的碗，一柄伞 | [澄汐][017] ↔ [雨棠][024] ↔ [海璃][028] | 澄汐曾扣住报船的碗，让逃离夫家的人换船，自此不替上岸的人选去处。海璃请雨棠一同守潮线，雨棠右腕曾替两排孩子挡过山洪，只开一个条件：她说想换人撑伞时，就真的接过去。 |
| 挂上栏杆的披帛 | [澄汐][017]、[海璃][028] ↔ [铃绡][026] | 两人的诊棚请舞者领呼吸，是最慢的病人定速度。渡船翻覆那晚，铃绡错过等了两年的首演；父亲却站在诊棚外看足全场，散场还嫌她第三圈转得急。下回，她决定给父亲留正中的座。 |

### 一口钟经过的手

| 留下的东西 | 牵连的人 | 后来怎样了 |
| --- | --- | --- |
| 缠在槌头的旧拳布 | [梅尽弦][137] ← [蔺鹤龄][139] → [贺紬][029] | 蔺鹤龄肯拿自己试徒弟的霜，却曾逼得想敲钟的外孙一听咳嗽就翻墙。她替梅尽弦挨足三层霜，救出石缝里的抬工，往后握不紧拳牌。外孙送来的小钟挂在门外，这回客人想敲多轻都行。 |
| 写着两个名字的瓦 | [梅尽弦][137] ↔ [戚流釉][046] | 一处窑房起火，流釉听见墙里还有童工。尽弦故意先冻住穿湿甲的窑主，脱下的护冰穿过开口，护住了孩子。窑主收回她租来取样的地，她丢了一年工钱。第二年孩子亲手烧了一块瓦，上面写着两个救他的人的名字。 |
| 架在山那边的钟 | [祁炊娘][042] → [莫观岳][136] ← [贺紬][029] | 窑主出钱，观岳开廊，本说好平分路钱。贺紬架钟让他听见岩壁另一头有人应。观岳改打自己这边的山嘴，保住了对面住户，绕远的路却赚不到钱；如今他替穷人家的送亲队免费抬鹿。 |
| 七只名签冲墙的旧匣 | [莫观岳][136] → [禾阙][065] | 禾家为失踪的父亲先后买回七副遗骨。抬工把七只匣抬进认领铺，特意把名字转向墙。禾阙现在仍先出示骨纹，免得下一位母亲也因为商人写下的名字领错了人。 |
| 敲三下的船栏 | [余映棠][102] → [贺紬][029] | 钟匠因替欠债人开舱而被扣。映棠听懂他敲船栏的舞步，顶着他的脸下船，让真钟匠留船逃走。后来她替妹妹作主，妹妹当面翻了旧账：当初钟匠求过你，我只请你陪我。 |
| 一张斜了角的证人席 | [贺紬][029] → [晏向隅][138] ↔ [雁十指][034] ← [薛耳石][087] | 向隅听钟练手，十指小时候跟薛耳石练口形。两门功课遇在一次指证上：证人席被挤歪，向隅的方框护住了包场人的女儿。他拆自己的障打翻来袭者，十指靠自己的壁手脱险。孩子后来又来买票，他的眉骨留下疤。 |

### 悬天台的座次图

| 留下的东西 | 牵连的人 | 后来怎样了 |
| --- | --- | --- |
| 一笔没还的预支工钱 | [黎梭音][141] → [解弦川][039] | 梭音想吊一台高空戏：谁摔，就由谁欠她一世。解弦川收了预支却不肯动工；她至今认定是他赖账，他至今留着那张把人命钉在座位上的图。 |
| 两圈可收的戏索 | [翁笑函][059] ← [黎梭音][141] ← [解弦川][039] | 翁笑函的偶戏曾替梭音撑起半个场子。后来梭音设暗扣不许她带人离开，自己却受了伤。解弦川把剩下的两圈报给梭音：要么留人，要么止血。梭音收线缝伤，看伶人走出白幕，把最后一场的工钱付清了。 |
| 给弟弟留的站位 | [解弦川][039] → [阮冬眠][133] → 一名敌兵 | 冬眠替解弦川守运输队，习惯替伤员腾地方。溃退时她给弟弟留好末位，弟弟却把拄拐的敌兵推进去。她没用本领把人换回来。次年伤兵带着木脚赴约，他们三个在桥口学互让半步的舞。 |
