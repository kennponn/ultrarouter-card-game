# 葬星之野 · 世界设定

> 时间基准：坠后第 317 年。
> 世界基调：灾后重建期。巨兽的躯体就是土地、港口和工厂，人们依附其上，也与它们协商。核心命题是"迁移"与"归属"：人到了新地方，还算不算有家。

---

## 一、世界概况

**坠星**：317 年前的长夜里，一座星座断成两列，较低的一列坠落地面。

- 坠落的古兽骨架在地面挣扎，改变了河床；一排兽牙顶出海面；一座山的林木被掀得根朝太阳。
- 死兽的咽喉后来成了港口，没死的兽仍在寻水而行。
- 坠星之前，雾林已有人嫁接梨枝，盐沼已有陶灶，文明并非从灾后才开始。

**天象**：有的星是恒星，有的会翻身，露出比月面还白的肚皮。有些"月食"邻村根本看不见，所以观星人先画一根晾衣竿的影子，再抬头。

**地域总称**：百骸洲。

## 二、生物与自然

| 名称             | 设定                                                         |
| ---------------- | ------------------------------------------------------------ |
| **活兽（驮兽）** | 坠星后仍活着的古兽，背上和肋间有人居住。肋间流出的温水曾救活冻僵的孩子，所以祖辈贴着它们搭棚定居。 |
| **赤母**         | 炉京一带的活兽。成年后每隔一段时间要自然换鳞，第九片背鳞正在松脱翘起。**匙柄街**就建在这片鳞上。她行动缓慢，不会为任何人加快脚步。 |
| **衔巢客**       | 天上的巨兽。每逢孵养季，衔走**自行松脱**的整片鳞，铺在云层深处承托幼崽。它们只取自行松脱的东西，至今没有人能用任何声音强迫成兽放下已叼起的东西。 |
| **幼年衔巢客**   | 会被特定的声音吸引，比如喉骨织机的"两短一长"振动。这是人类唯一确认的、能影响天兽的手段，只对幼兽有效。 |
| **天兽（成群）** | 成年天兽成群掠过时几乎遮住星空，海上称这段时间为"无灯旬"。   |
| **驮昼鼹**       | 悬天台的学舍里，晒背后回洞给幼崽放光，作物的根朝光生长。学舍菜畦因此长在头顶，学校种菜靠的是它，而不是法师。 |
| **云褥葵**       | 衔巢客软草中的植物，会眨眼。借到雾林育苗棚后，底下的菜苗接不到雾水，如今晒冬被的人反而抢着借。 |
| **续句蚌**       | 能学死者的旧声，并把后来听到的话接在旧声后面。               |
| **缀岸螺**       | 成对出现。同时发亮，只表示潮口"到开合的时候了"。             |

> **关于云巢**：悬天台收到过一片从高空脱落的旧鳞，背面平着长了层烟黑，夹一道细细的鱼骨。有人说是灶灰，有人说衔巢客也吃鱼。没有任何人从云巢回来过，所以那里能不能呼吸、有没有人家，目前无人知晓。

## 三、借官与接班蜕

**借官**：死兽的器官仍保留生前的功能和"记忆"。

- 喉骨里放梭子，按旧节拍往来，能发出那头兽生前的声音。
- 死去的口与咽，有时还记得如何把同一口水咽下去。
- 借的是**留在地上的器官**，不是役使死者的灵魂。
- 换座厂房，织机照样出布，但不会招来天上的幼兽。幼兽认的是那副具体的喉骨。

**接班蜕**：骨仓有时在交班时撑起一件空工衣，照旧搬货。

- 搬粮的是蜕，真正的杂工可能还困在别处。
- 炉京的孩子很早就学会："认出一份活儿，不等于认出了做活的人。"

## 四、地址与交通体系

### 4.1 门牌的三种写法

邮差带两本册子：一本画地，一本记谁要从谁身边经过。问路的第一句通常是："你找那栋房子，还是找住在里边的人？"

| 门牌     | 含义                                                         | 送信方式                                       | 易错点                                                       |
| -------- | ------------------------------------------------------------ | ---------------------------------------------- | ------------------------------------------------------------ |
| **钉址** | 房基落在不移动的山岩或死骨上，如长栈月台、白角关磨坊。       | 记住石碑位置，来年仍可找到。                   | 去年挨着的邻街今天未必还在。火车能到月台，不能沿轨开上赤母。 |
| **驮址** | 门牌随活兽、船队或悬篮移动。例：匙柄街写作"赤母，肩后第九鳞"。 | 不知她走到哪一站，就交给下一位等她靠肩的栈工。 | 白礁沉没后，居民仍按旧街排早餐船。认得门牌能找到人，照旧海图下潜只能找到屋顶。 |
| **潮口** | 两处远隔的器官偶尔重新接通。平日两处水洼不通同一条河。       | 需写清入口、出口和对岸接货人，交给**开渡人**。 | 缀岸螺发亮只说明开合时间到了。若出口被旧船梁挡住，粮袋照样过不来。 |

### 4.2 路线实例（盐海五更港 → 匙柄街）

- **老路**：运河驳船 → 铁路 → 炉京长栈 → 等赤母的肩经过月台，桥工放下短桥 → 过肩步行两条巷到产院。
- **潮口路**：五更港退潮时，托人从古兽口腔送往千里外的**白泉**；守泉人验明出口才接货，再由白角关铁路运往长栈。
  - 此路**只在五更港到白泉这个方向验证过**。收条须由陆路送回，不得塞回泉眼。
- 两条路的终点都要等赤母，她不会为任何一袋面加快速度。

### 4.3 潮口互信的建立

两地之间不会自动互信。今年春天，五更港的两排船架并上同一根绞轴，合架时吞下一艘宽底货船。白泉先吐出船钟，再吐出一个水手。

- 失船家属不肯承认千里外的一口泉。船工当众剖开一只橘子，送半只入水，另半只留给船长的妻子。
- 白泉那头沿驿路送回捞起的半只，橘核都能合上。
- 船长的妻子这才在新图上给白泉画了圈，但**拒绝在丈夫名字旁画圈销账**。

> 设定要点：潮口能证明"物"的通路，不能证明"人"的下落。

### 4.4 地图的类型

- **乐谱式地图**：悬天台的逐星长阶高悬在雾林上方，足下能望见种菜人，最近的吊篮却半日才合拢一次；相隔千里的磨坊与港口，却可能在某个退潮的清晨近得"只差一个橘子皮"。
- **兽腹花纹图**：远洋舟师只画每年经过的兽腹花纹。有些人跟同一群兽已度过四代婚丧。这些地方不归长栈排班，也不因炉京从未去过就没有人家。

## 六、地方文化

### 6.1 雾林：嫁接与树权

- **婚俗**：新人各拿一把剪，领对方认自己田里的母枝。
- **果权**：花在邻家开，原来照顾它的人也有权摘果。
- **榕君**：大饥年，茧伯把成片快死的接穗嫁到自己背上，整冬站着睡，被尊称榕君。他的后人认为"天下人的树都从父亲身上长过"，因此要求年年上缴收成。
- **空碟礼**：宴席上留空碟，不是等亡者回来，而是表明主人仍活着，也有权拒绝用别的豆子赔偿。
- 此类权属争议比帝国铁路更早扎根。

### 6.2 远洋舟师：无灯旬

- **无灯旬**：十来天，成年天兽遮蔽星空，舟师只凭它们掠水时腹面倒影的花纹辨路。
- **领航传承**：不总是父传长子。若一家连着三年只见自家熟悉的那一小群兽，就把孩子送去别的航路的船上过冬，回来画出长辈没见过的腹纹。
- 航期错开，亲兄妹有时四五年才在海上碰一回头。
- **交会礼**：两队相遇，先越船递过去的是**画像**，而不是货单。商人再有钱也买不到领航位。

### 6.3 炉京：废候车室的传说

- 钟停在零点，封死窗口偶尔吐出单程票，印着从未通车的站名。
- 最早有人看到栅栏内的座椅一张张回暖，以为失踪亲人回来。至今座椅暖过，却没有人从那班车上接回过亲人。
- 门口一直有人替归客备一碗"不放葱的面"。
- **异闻调查局**不许卖往返票，也不去质问备面人凭什么相信那个人不吃葱。

### 6.4 悬天台：头朝下的学舍

学舍中人头朝下进入，地下菜畦翻到头顶。其农业依赖驮昼鼹的光，封死晒台，菜就停长。当地人认为：认清一只活物，比再请一个厉害的人重要得多。

## 七、力量体系

### 7.1 天赋异能

- 来源多样：家传、身体、器物，或手艺练到极致，彼此并不同源。
- 异能有明确边界。示例：
  - **海璃**：需要一口**活人的呼气**才能起和声。能听到盐海送上岸的死者最后的声音，却接不上他的下一口气。
  - **雁十指**：能让灰墙长出自己的耳朵，隔砖听到勺子敲碗。家传能力；她后来走上"观众"途径，也不能隔墙判人有罪。
  - **焦檐祖**：能把一间旧屋收到胸前带人转移。屋内人若不愿进，门钥匙交给对方，让对方从里面扣门。
  - **铸王**：以骨冠逼赤母低头。
- 炉京的**请工榜**把各类异能者列在一起，但这不代表他们同出一源。

### 7.2 非凡途径（瓶中之力）

- 旧典记载 **22 条途径**，每条有序列 **9 → 0**。
  - 序列 4 起进入**半神**之列。
  - 序列 0 才是神位。
- **魔药**：每一阶需要对应的**非凡特性**、**配方**与**消化**，部分关口还需**仪式**。
- **消化**：通过"扮演"完成，即活成药名所代表的那种人。
  - 例：寻宝女王服用暴君途径首剂"水手"，第二天就能在湿桅顶站稳，但同船人骂她，因为底舱进水，不需要一个站得高的好看人物。她下来轮班，每个下雨夜都去舀水，药才渐渐消化。
  - 药师告诫：靠岸后要记得自己是谁。
- **失控风险**：未消化便服下一剂，可能失控，甚至无法维持形体。
- **治愈的局限**：圣愈用泉雨治好过一舱人的寒症，却无法让失控者身上的异肢退回。
- **非凡特性的析出**：人死后特性析出，相近者互相吸引，部分旧物因此需要封印。
- **个人物品与能力不可转让**：寻宝女王的藏宝图（能看出沟底更重）在她服药前就存在；换同序列的人掌舵，图也不会起金线。

### 7.3 奇物与封印

- 守灵家人听海，守匣人盯死者戴过的手套，二者等待的东西不同。
- **盐海教堂**以"一季丧粮"换取需封存的物件，曾从婴儿床上收走一只会咬人的围兜。
- 也有穷人交出了母亲用了半辈子、毫无异常的杯子。
- **争议**：谁有资格判定某物是"遗物"还是"遗产"，每年都要吵一次。
- **偏席伞**：奇物。能把同一只缠红布的手在表决中投成七只，需换角度重新计票才能识破。
- **还彩印**：盐海七户持有。能翻出真实的印迹，但不能证明睡着的人曾答应搬家。

## 八、势力与制度

### 8.1 主要势力

| 势力                                     | 掌握的资源                 | 立场与诉求                                                   |
| ---------------------------------------- | -------------------------- | ------------------------------------------------------------ |
| **王室铁路**（铸王一脉，祖先为"看火人"） | 煤车、冬粮、货车皮         | 愿提供搬迁货车，条件是赤母今年也要按铁路时刻表靠肩。想给赤母戴新骨冠，目前尚无许可。 |
| **盐海七户**                             | 渡船、还彩印、月影王庭席位 | 七支替人寻尸起家的领港船队。关注"街去了天上，屋契还在不在"，若房屋离地即算绝户，将激起白礁人清算。希望用一枚印替所有病家统一签字，长栈不接受。 |
| **长栈桥户**                             | 桥板、吊篮                 | 唯有他们能把桥板放到运动的肩骨上。部分人想涨吊篮租。         |
| **炉京织工**                             | 能引来天兽的喉骨织机       | 愿留一台织机给幼兽听，不愿把工钱系在成兽是否绕开产院上。     |
| **异闻调查局**                           | 遮蔽信息的权限             | 下设**灯使**（查痕）、**聆潮人**（辨声）、**守阈人**（守门点数进出）。不撕寻亲广告，只替不愿公开家门的人遮去地址。 |
| **盐海教堂**                             | 奇物封存权                 | 以丧粮换封存物，处理遗物与遗产的归属。                       |
| **药师**                                 | 魔药配方与扮演指导         | 把魔药消化称为"扮演"，并提醒服药者保持自我认知。             |

### 8.2 两张榜（互不混用）

- **异能榜**：回答"这一次先邀请谁出工并带工钱"。同一人在不同任务下排名不同，如带得走病房的人，换成找沉货的活就不是榜首。
- **奇物榜**：回答"某物落错手，会牵连多少没答应的人"。
- **规则**：能邀人出工，不等于能搜他的药；知道谁保管奇物，也不等于有权令其当日交出。

### 8.3 居住与迁移制度

- **两姓门楣**：长栈的新门上嵌有旧住户的旧门槛，以此证明居住事实。但旧木易朽，磨损后不再能作证。
- **居住证明**：不依赖屋契。可由互不相干的**两名街坊分别作证再合证**，如共用炉灶的邻居出示轮夜生火的缺齿木筹，每日收泔水的老人说出住户生活细节。
- **过渡房**：长栈给母女登记同一间过渡房。不裁决原屋产权，也不以分离亲人为代价分配床位。
- **名册原则**：下一批没有旧槛的街坊，也可凭其他居住证据申请，不得因核契未完而被挡在车外。
- **表决规则**：重要表决须换角度重复一次，有人公开说"不"，此"不"与帝王的命令在放不放桥这一刻同样有效。

### 8.4 迁移的双重问题

> **怎样下街，和下街之后还有没有家，是两件事。**

- **运送问题**：窄桥只能侧身通过，须平放的病床抬不过去；需要焦檐祖这类能收屋的人，或空出平整的月台。
- **归属问题**：长栈的撤离名册只登记铺面东家，不含住在铺后的雇工与家属。这类人的居住权需要另行证明。

## 九、历史事件（三桩旧事）

### 9.1 白礁（坠后 308 年）

- 齿床下的城倒灌，七艘船被同一条索拴住。
- 海璃的哥哥困在末船，起调等她唱"并"让前船回桨，海璃唱了"分"。前六条船生还，末船沉没。
- 后果：
  - 白礁人至今仍每天早晨按旧街排船卖饭，仍愿做街坊，但没有人肯替"当晚的第七条船"销账。
  - 焦檐祖曾把旧屋收到胸前救人，一个孩子认出他是旧日船行的收债人，不愿进入。檐祖交出钥匙，让孩子自己从里面扣门。
  - 九年后，产院第一个问他的也是："住进去的人肯出来时，谁来开门？"

### 9.2 白角关（311 年）

- 铸王乌铎用骨冠逼赤母低头。关口降旗后，她的下颚仍压向城墙。
- 将军**龙音**折断自己的角，卡死骨冠，赤母才偏头。
- 城门下的人活下来，背外缘的七百骑全部坠峡，包括把龙音养大的**赫连岫**。
- **星墙**在门口举盾，见妹妹**窦红杏**也在那支队伍里，仍没有转盾，因为转开就护不住放下武器的人。
- 此日的两种叫法："开门日"与"断角夜"。星墙每年去两处吃饭：第一处不庆祝妹妹的死，第二处不为投降道歉。
- 影响：今日再有人提议用新骨冠让赤母在月台多停，关城有权要求先听龙背上的人说话。

### 9.3 炉京（317 年）

- 两百架织机立于死兽喉骨上。二十一名聋织工最先发现机脚按"两短一长"振动，最先跟着声源走的是一头幼年衔巢客。
- 织工把一台织机挪到同一副喉骨伸出的晒布场，幼兽也把衔回的软草移了过去。
- 云褥葵由此借到雾林，引发育苗棚的缺水问题，同时成为晒冬被的抢手资源。
- 结论：幼兽能被声音吸引，成兽取走的却是自行松脱的鳞，**至今没有人能用声音让成兽放下东西**。这是匙柄街必须搬迁的根本原因。

## 十、当前局势（坠后 317 年）

### 10.1 匙柄街的处境

- 赤母的第九鳞松脱，鳞面已倾斜。衔巢客孵养季将至，上一次被衔走的是一截无人使用的木栈，这一次鳞上有人。
- 行动能力强的居民可立即收拾行李离开，困难集中在无法移动的病人、产妇和新生儿。
- 公炉（最重的一口）仍在鳞上。
- 赤母下一次靠肩的时间尚无法确定，整条街铺面的补偿责任仍在争议中。

### 10.2 各方关系

- 铁路方愿出车皮，但要求赤母按时刻表靠肩；
- 盐海七户愿借渡船，想以统一印章代签；
- 长栈桥户和炉京织工各自掌握关键资源，但不愿被互相绑定；
- 白礁后裔与祖辈对"云巢"持不同态度：年轻人期待天上有第二条街，祖辈不许把"也许"写进迁居告示。

### 10.3 并行存在的其他争端

- 雾林四户人家在讨回被王宴毁掉的种芽，宴席上空碟尚在；
- 倒悬戏台为一位离家十三年的母亲保留座位；
- 白角关两侧即将迎来同一天的两场祭礼；
- 盐海的海璃案：她在白礁听到哥哥嘲笑红靴，但那双靴子是他死后第八年才借到的。续句蚌能学死者旧声并续接后来听到的话，这提供了调查方向，却无法据此定罪某个活人；
- 白泉：失船至今只回来一只船钟和一个水手，半只橘子证明入口通向何处，没有回答船长在哪里。
