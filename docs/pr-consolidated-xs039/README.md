## 技能进入真实战斗

| 技能 | 本次生效行为 |
| --- | --- |
| 普攻 | 按特攻结算、增加怒气，每大回合最多回复 1 亮榫点，初始 2、上限 3 |
| 对榫换位 | 消耗 1 榫、3 次行动冷却。危急或受控时救援最低血比友方、与最高当前生命另一友方换位、治疗并净化；捆绑阻止换位。否则切开最高当前攻击敌人并植入脉冲 |
| 空壳留震·三榫共鸣 | 消耗 100 怒，打击主目标所在列，无视 25% 特防；主目标捆绑／重压时追加倍率。满 3 榫自动花 2 榫展开 2 大回合领域，留下 1 榫救助 |
| 亮榫点·留震 | 原生脉冲在宿主两次行动开始后引爆，邻位溅射，向无脉冲的最低血比敌人派生一次；每人 2 枚、每施法者 4 枚，衍生不继续传播，净化不爆炸 |
| 衣角接坠 | 开场为自己和最高攻击另一队友留印；致命伤消耗 1 榫救助，恢复受上限约束的记录生命、净化两项并短暂减伤，每个标记只能救一次。队伍累计三个新负面状态触发一次回访净化，受控／压制时不计入 |

伤害、资源、换位、救助、胜负和奖励由 Go 服务端结算。客户端播放完整快照，保留旧卡的战斗日志、技能播报与立绘切入，并加载新卡四张技能特效图；跳过和刷新也以服务器战报为准。

**来源范围：仅初始 5 星机制已实装。** 来源中的 8／11 星专属能力和星霜演化是设计预览，图鉴明确标注尚未启用。已有通用培养继续适用。尚未发布的故事关联角色不激活羁绊。

## 发现并修复的问题

从 #8、#9 的失败 CI 日志确认，原检查同时包含两个旧基线夹具不匹配，以及候选中的公会商店刷新断言过时。它们不是数据库升级丢失数据的证据。基线仍固定并保留原失败记录，候选按当前规则重新验证。
