# 周限定召唤、商店经济与公会讨伐奖励

本次更新基于六人公会远征版本（上游 PR #7）。保留现有「强者世界」界面，不包含海贼王界面复刻、模拟器文件或外部游戏素材。实拍图来自本项目的本地虚构账号，托管在独立图床。

- 取消站点 E 兑换游戏代币和每日战斗代币总量限制。竞技场、日常副本和远征发专属币，商店按北京时间 09 / 14 / 21 点补个人库存；体力礼包分 30 / 60 / 120 三档。
- 强者世界每周轮换一位 SSR，周一至周五仅用限定券抽；每抽至多一枚当期碎片，另设积分箱及前 20 名碎片奖励。SSR 的 80 枚同卡碎片可手动合成。宝石和芯片各有一次每日免费抽，后续可选本池券或代币。
- 每日任务增加排名挑战、装备与技能培养，积分箱奖励直接入包；放大角色工坊，调整培养开销并核对副本金币收入。

公会首领的生命由全会共同削减，个人打完两场常常不会看到首领倒下。本次把回报拆成两部分：每次有效参战立即得到培养资源；公会通关后，参加过这个阶段的成员还可领取一份更大的周奖励。首领难度、每日次数和所需体力不变。没有新增直接发放的站点余额、金币或游戏代币。

## 经济复算

每条路线模拟 2,048 个固定种子、连续 7 天，13 条路线共 186,368 个模拟玩家日。下表为每个账号每日均值；模拟假设第 50 名成熟账号已解锁相应副本，普通刷关胜率 97%，不把任何阶段首通计作固定日薪。金币和代币分别记账，不允许反向兑换。

| 路线 | 金币收入 / 需求 | 代币收入 / 需求 | 一周付清整套培养计划 |
| --- | ---: | ---: | ---: |
| 全勤，常规培养 | 12,233 / 11,994 | 500.2 / 496 | 62.7% |
| 三档代币体力全买，余力优先噩梦裂隙 | 17,277 / 11,994 | 572.2 / 676 | 0% |
| 全勤但不参加公会 | 12,732 / 11,994 | 379.1 / 496 | 0% |

买满三档共花 180 代币换 90 体力。刷本**能够缓解金币短缺**，代价是每天约缺 104 代币；不能把多出的金币与少掉的代币看成同一种收入。公会币增发后只调整了三锁洗练（195 → 210），无锁及一、二锁未加价。基准路线若一周少做一次三锁洗练，能付清余下培养清单的比例从 62.7% 上升到 99.6%。完整对照见项目根目录 `VALIDATION.md`；复算命令为 `node scripts/simulate-economy.js --compare`。

## 验证边界

前端、公会、强者世界和经济专项 24 项通过，另有 5 项锁定、回收与培养用例通过；本地启动器 `--check` 通过。正式 Go 结算按服务端配置计奖，不接收客户端传来的数量；已更新 Go 单场、双场、并发次数、背包容量与首通断言。本机没有 Go、Docker 或共享限额执行器，未运行 Go 与三库集成回归。未部署，不能以模拟或截图代替正式数据库验收。
